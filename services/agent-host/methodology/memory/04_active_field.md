# 当前局面包

当前局面包是主线 Agent 每轮优先读取的压缩上下文，放在：

```text
07_上下文包/
```

它应包含：

- 当前命盘周期。
- 当前主题。
- 当前目标。
- 当前压力。
- 当前重要关系。
- 当前资源状态。
- open hypotheses。
- pending confirmations。
- recent key events。

当前局面包不是事实库，只是读取缓存。

事实仍在 Basic Memory Markdown notes 中：

- `01_命/`
- `02_愿/`
- `03_境/`
- `04_缘/`
- `05_力/`
- `06_功曹/`

如果当前局面包和原始 notes 冲突，以原始 notes 和用户原文为准。
