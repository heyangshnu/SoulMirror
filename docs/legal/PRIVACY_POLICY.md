## 二、我们收集哪些信息

我们遵循 **合法、正当、必要、诚信** 原则，仅为实现产品功能而收集信息，不收集与功能无关的信息。

### 2.1 您主动提供的信息

| 场景 | 信息类型 | 用途 |
|------|----------|------|
| 注册/登录 | 手机号码、登录密码（加密存储） | 账号创建、身份验证、账号安全 |
| 个人资料（可选） | 昵称、年龄段、职业、关注方向等 | 个性化对话与报告 |
| 紫微命盘 | 出生日期、出生时辰、性别、历法、出生地、经度等 | 排盘、生成解读报告 |
| 探索测试 | MBTI 作答、八字/塔罗/手相等测试输入 | 生成测试报告、磁场匹配画像 |
| 心镜对话 | 您输入的文字消息 | AI 对话、生成摘要、改进回复质量 |
| 语音日记（若使用） | 语音或转写文字 | 个性化上下文 |
| 磁场匹配/社交 | 匹配开关状态、聊天申请与好友消息 | 缘分推荐、好友聊天 |
| 手相功能（若使用） | 您上传的手部照片 | 手相分析（见下文存储期限） |

### 2.2 我们自动收集的信息

| 类型 | 说明 |
|------|------|
| 设备与日志 | 设备型号、操作系统版本、应用版本、接口请求日志（不含密码明文） |
| 网络信息 | IP 地址、请求时间（用于安全与排障） |

我们不会主动收集 **精确地理位置轨迹**；出生地等信息由您自愿填写，用于命理相关功能。

### 2.3 敏感个人信息说明

生辰、性别、健康相关自述、心理测试作答等，可能属于 **敏感个人信息**。我们仅在您 **明确同意** 并使用相关功能时处理，且采取加密传输、访问控制等措施。您可拒绝提供，但将无法使用对应功能。

## 三、我们如何使用信息

我们仅在以下目的范围内使用您的信息：

1. **提供核心服务**：账号管理、紫微解读、探索测试、AI 对话、报告存储与展示。  
2. **个性化体验**：根据命盘、报告摘要、对话上下文生成更贴合的 AI 回复（经去标识化摘要处理，不向其他用户公开您的完整报告与对话）。  
3. **磁场匹配（需您主动开启）**：在匹配功能开启后，向其他已开启匹配的用户展示 **昵称、匹配相关标签（如 MBTI、契合度等）**，不展示手机号、密码、完整生辰与完整对话内容。  
4. **安全与合规**：身份验证、反欺诈、故障排查、履行法律法规义务。  
5. **改进产品**：在 **去标识化或聚合统计** 前提下分析功能使用情况。

**我们不会** 将您的个人信息出售给第三方。

## 四、AI 与第三方服务

为实现 AI 解读与对话，我们可能将必要信息传输至 **第三方大模型服务提供商**（如 DeepSeek 等），传输内容限于完成功能所需的最小范围（例如：排盘结果摘要、您当次输入的消息、报告生成所需字段）。

我们会：

- 与服务商约定数据处理目的、保密与安全要求；  
- 不要求服务商将您的数据用于其模型训练的，应在合同中予以约定（以实际合同为准）；  
- 在境内存储您的账号与业务数据（见第五节）。

第三方服务商名单或变更，我们将通过应用内公告或政策更新页说明。

## 五、信息存储与保护

| 项目 | 说明 |
|------|------|
| 存储地点 | 中华人民共和国境内服务器 |
| 存储期限 | 账号存续期间；注销后按第五节删除或匿名化 |

互联网环境并非绝对安全，请您妥善保管账号密码，勿向他人泄露。

## 六、信息共享、转让与公开披露

我们 **不会** 与无关第三方共享您的个人信息，除非：

1. 获得您的 **单独同意**；  
2. 为履行法定义务、司法或行政机关依法要求；  
3. 为保护您、我们或其他用户的生命、财产安全所必需；  
4. 因业务转让、合并等导致个人信息处理者变更时，我们将通过应用内公告等方式告知，并依法重新征得您的同意（如适用）。

## 七、您的权利

根据《个人信息保护法》等规定，您享有：

| 权利 | 操作方式 |
|------|----------|
| 查阅、复制 | 应用内「我的」查看报告与资料；可邮件申请导出 |
| 更正、补充 | 应用内修改资料或联系客服 |
| 删除 | 删除部分对话/报告（视功能支持）；注销账号删除关联数据 |
| 撤回同意 | 关闭磁场匹配、停止使用可选功能；注销账号 |
| 注销账号 | 应用内「一键删号」或联系客服（软删除后 **30 日** 内硬删除，法律法规另有要求的除外） |
| 拒绝匹配 | 不开启「磁场匹配」即不会进入推荐列表 |

未成年人请在监护人指导下使用；我们建议 **未满 14 周岁** 用户不要注册。
